# Projekt Novej zmluvy urbariátu Dulova Ves p.s.

- základnou po6iadavkou pre prípravu novej zmluvy je sfunkčnenie spoločenstva týkajúce sa možnosti zápisu zmien do registra a nastavenie základných rámcov fungovania spoločenstva, vyhádzanie veci, ktoré su spravované
  zákonom [97/2013 o Pozemkových spoločenstvách](https://www.slov-lex.sk/ezbierky/pravne-predpisy/SK/ZZ/2013/97/), sú v rozpore so zákonom, ale v rozpore so inými základnými princípmi, napr. matematiky, práca a naplniť stanovy, ktoré su potrebné pre základné fungovanie pozemkového spoločenstva.
