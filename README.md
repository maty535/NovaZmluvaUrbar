# Projekt Novej zmluvy urbariátu Dulova Ves p.s.

- základnym faktorom pre prípravu novej zmluvy je sfunkčnenie spoločenstva týkajúce sa možnosti zápisu zmien do registra a nastavenie základných rámcov fungovania spoločenstva, vyhádzanieveci, ktoré su spravované
  zákonom [97/2013 o Pozemkových spoločenstvách](https://www.slov-lex.sk/ezbierky/pravne-predpisy/SK/ZZ/2013/97/) a naplniť stanovy, ktoré su potrebné pre základné fungovanie pozemkového spoločenstva.
