# Projekt Novej zmluvy urbariátu Dulova Ves p.s.

- základnou požiadavkou pre prípravu novej zmluvy je sfunkčnenie spoločenstva týkajúce sa možnosti zápisu zmien do registra pozemkových spoločenstiev a nastavenie základných rámcov fungovania spoločenstva, vyhádzanie veci, ktoré sú priamo ošetrené zákonom [97/2013 o Pozemkových spoločenstvách](https://www.slov-lex.sk/ezbierky/pravne-predpisy/SK/ZZ/2013/97/), sú v rozpore s týmto zákonom, ale v rozpore so inými základnými právnými a inými princípmi, napr. matematiky. 

- T.z. je potrebné naplniť stanovy obsahom, ktorý je minimálne potrebný pre efektívne a hospodárne fungovanie pozemkového spoločenstva.
